# 2026-10-23

- 在 AdminDivision 仓库搭建了 OSM 行政区划提取 Maven 项目（Spring Boot 3.2.5 + Java 17）。
- 依赖：osmosis-core/osmosis-pbf 0.49.2（读取器为 crosby.binary.osmosis.OsmosisReader，0.49 已移除旧 PbfReader 类）、fastutil、jackson-core。
- 核心实现：三遍流式扫描 PBF（relations→ways→nodes），环组装（端点拼接）、洞按最小包含外环分配、Visvalingam-Whyatt 简化（阈值=factor²）、流式 GeoJSON 输出（OSMB 格式：osm_id/boundary/admin_level/parents 负 ID 链/name/local_name/name_en/all_tags，7 位小数）。
- 踩坑：RingAssembler 用 `!=` 比较装箱 Long 导致所有环判为未闭合（首版 0 特征），改用 equals 后修复。
- 导出参数对照 osm-boundaries.com：admin-levels / boundary-types / bbox / simplify(度) / include-tags / hierarchy / srid(仅4326) / precision。
- 用用户提供的 anhui.osm.pbf 实测：--admin-levels=4,6,8 --simplify=0.0005 输出 1436 个特征（Polygon 1361 / MultiPolygon 75），JSON 校验通过，5.2 秒完成。
- 本机 Maven 本地仓库在 I:\repository；Geofabrik/BBBike 下载被代理拦截或极慢。
- 应用户要求将 groupId/包名由 cc.xqhui 统一改为 io.github.qmjy（目录迁移至 io/github/qmjy/admindivision），重建并回归测试通过（anhui 1436 特征）。
- 用户将 spring-boot-starter-parent 升级到 4.2.0-M2：代码无需改动即可编译运行（jackson-core 解析为 2.21.6）；Boot 4 BOM 将 protobuf-java 管到 4.35.1，导致 osmosis-pbf 老 gencode 报 "Vulnerable protobuf" 警告，通过 <protobuf-java.version>3.25.5</protobuf-java.version> 固定解决（含 GHSA-h4h5-3hr4-j3g2 运行时修复）。Boot 4.2 BOM 的属性名是 protobuf-java.version（带连字符）。
